# Worklog Entry Template

Required in the same PR for every change that affects the product (see `AGENTS.md`).

File: `docs/agent-worklog/<topic>.md` (kebab-case). Append to an existing topic file if one fits — avoid near-duplicate files for closely related changes.

```markdown
# <Topic>

## Changes
- What was done and why.

## Decisions
- Key choices made and alternatives rejected.

## Testing
- How changes were verified.
```
